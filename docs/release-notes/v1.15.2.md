# v1.15.2 — Product Language

## Summary

A small patch that changes what the interface says, not what it does. From
the owner's screenshot audit: the governance rail and the activity timeline
were rendering machine tokens (`conversation`, `clarification_needed`,
`explicit_plan`) directly from `task.intent_kind`. The spelling was never
wrong — the language was. A person reads *needs your choice*, not
*clarification_needed*.

## What changed

- **INTENT_LABEL** in the Work governance rail: intent badges now read
  `ordinary conversation` / `planning requested` / `direct execution` /
  `needs your choice`.
- **INTENT_PRODUCT_LABEL** in `lib/agent/events.ts`: the "Intent classified"
  timeline row shows the same human words — one vocabulary across every
  surface, the same single-mapping pattern as `STATUS_LABEL`.
- **Xeo Flow trail overflow**: the stage pills live in a `min-w-0
  overflow-x-auto` wrapper, so they shrink and scroll instead of clipping
  under the Tabs row (the audit capture showed the trail truncated at the
  container edge).

## Forensic note

The screenshot's suspected misspelling was investigated at 4x and 12x zoom
character reads: it is an image-compression artifact — the source string and
full git history are clean. The actionable defects were the machine-token
language and the overflow, both fixed here.
