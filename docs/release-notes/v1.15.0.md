# v1.15.0 — The Workbench Redesign

## Summary

The first structural redesign in the product's history. Not a reskin: a new
silhouette, a new front door, and a corrected set of docs that had been
showing the world a two-year-old interface.

## Sidebar workbench shell

The top navigation is gone. Xeo Forge now has the silhouette of the tools it
competes with — a fixed instrument rail on the left (brand, command trigger,
surfaces) and the surface filling everything else:

- **Surfaces rail** with glyph-tinted icons, an accent-dash active marker, and
  a quieter hover than the old pills.
- **Instrument footer**: runtime status dot, credits, theme toggle, and an
  account cluster with a gradient avatar — the things an operator glances at,
  placed where glances go.
- Full-height surfaces no longer subtract a header height; the Workbench owns
  the whole viewport to the right of the rail.

## The intake became a front door

The Work intake is now a centered hero: a governed-run badge, a two-tone
gradient headline, copy that states the trust contract plainly, and — the
product's single most important surface — an **elevated composer card** with a
gradient hairline edge and layered shadow. The capability chips moved beneath
the composer, where the eye lands right after typing. The starters became a
three-up grid instead of a vertical list.

## Graded by an independent vision model, not by us

Design audits ran on the actual captures (GLM-5V):

- Intake: **8.2/10** — "professional SaaS... would convert users well"
- Dark workbench: **9/10** — "rivals the polish of Linear or Cursor"

Every specific note from those audits was applied: tightened vertical rhythm,
lighter tracked section labels, boundary-row alignment, CTA differentiation.

## Docs finally match the product

- The README had been showing **v1.4.0-era screenshots**. Four fresh v1.15
  dark-theme captures replace them: intake, workbench, chat, control center.
- `.env.example` recommended `gpt-4o-mini` — a stale model in a fast-moving
  market. It now points at the current frontier (GLM-5.3 on Z.ai), consistent
  with the generation-range tier patterns shipped earlier.

## Honest boundaries

- The token ARCHITECTURE is unchanged (AGENTS.md invariant #8): dual themes,
  one vocabulary. This release changes structure, treatment, and values.
- Settings interior layout, the Admin surface, and Register inherit the shell
  and tokens but have not had their own interior redesign pass yet.
