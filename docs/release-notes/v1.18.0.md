# v1.18.0 — The Hardening Release

## Summary

Everything this release fixes was **proven before it was fixed**: a live
deep-inspection session ran the packaged v1.17.0 app end-to-end (real
governed task, real decision gate, real provider failure), and a full code
review read the loop, guards, and execution boundary line by line. Each fix
below is tied to a demonstrated defect and pinned by new tests.

## The consecutive-empty counter actually resets

The declaration comment promised `Reset on any non-empty response`; the
reset did not exist. Three empty responses **scattered across the lifetime
of a long productive run** failed the task with "the provider or model is
misconfigured". Now any productive stream (text, reasoning, or tool calls)
resets the counter — it is genuinely consecutive-only. Pinned in
`test/v118-hardening.test.ts`.

## Python tooling: Windows-first rewrite

`CodeTool.python()` piped snippets through `printf '%s' '<escaped>'` — shell
syntax that (a) never works where `exec()` runs cmd.exe, i.e. every Windows
desktop install, and (b) broke on any snippet containing a single quote.
The snippet is now written with `fs.writeFileSync` and executed directly,
with per-platform interpreter resolution (`py -3 || python` on Windows —
bare `python3` resolves to the Microsoft Store stub there). The entire
quoting class of bugs is gone, and the temp file cleans up even when the
command is denied upstream.

## Audit-stream parity on mid-batch credit failure

The parallel read-only batch debited credits and emitted `tool_call` events
in order; a debit failure mid-batch failed the run leaving emitted
`tool_call` events without any matching observation — breaking the
diff-receipt contract. Now every already-emitted call is closed with an
explicit error `tool_result` event before the run fails.

## Language parity for the autonomy guards

The runtime instructs the model to answer in the user's detected language,
but every build-mode question detector was English-only: an Arabic-language
run asking "هل تريدني أن أتابع؟" instead of acting slipped past the guard.
Arabic patterns are now first-class detectors, and `detectLanguage` drops
its Arabic threshold from 15% to 8% — realistic mixed goals (Arabic prose +
English identifiers) were being classified as English, breaking the
LANGUAGE AFFINITY contract.

## security-model.md: claims written down

A new top-level document states what each layer defends, what it explicitly
does not defend, and the known bypass classes verbatim (interpreters given
files, `node -e fetch`, short-form loopback IPs, urllib vs socket). The
symlink/code_execute TOCTOU seam is documented with its mitigation and its
deferral to the isolated runtime profile. Honest boundaries are a product
contract; now they are also inspectable.

## Verification

- New `test/v118-hardening.test.ts` pins each fix at the source-contract level.
- The cancellation source-contract test is CRLF-agnostic (Windows checkouts).
