# v1.17.0 — Stop, Classify, Trust

## Summary

Three fixes from the executive audit's risk register, each end-to-end and
test-pinned — plus the milestone underneath them all: this release follows
the **first real agent runs with a live model** (merged in the phase-0 PR),
which validated the governance kernel end-to-end before these controls were
added on top.

## Cancellation: the missing "stop"

The product could start runs but never stop them — closing the SSE tab did
nothing to the server-side loop. Now:

- `POST /api/tasks/:id/cancel` (owner-checked, terminal-session cleanup,
  event-trailed transition to `cancelled`, honest 409 on non-running tasks).
- The agent loop registers an AbortController, checks the signal every
  iteration, and passes it INTO the provider stream — a cancel stops token
  fetching server-side. An abort during a model call records `cancelled`,
  not `failed`.
- `cancelled` is a first-class terminal status (types, timeline, badge,
  runner idempotency) and the Workbench shows a Cancel control while running.
- **Honest boundary:** cancellation is cooperative; an in-flight long tool
  completes first (bounded by per-tool timeouts). Pause/resume/checkpoint
  remain the next lifecycle milestone.

## Browser policy: one contract, two layers

The audit's sharpest finding: `browser-bridge.cjs` enforced `click/type` as
sensitive while `browser.ts` enforced `navigate/click/type` — the extension
path was the weaker door. The bridge now mirrors the agent layer exactly,
and a contract test asserts both layers stay in lockstep so the divergence
class cannot silently return.

## Capability manifest: the vocabulary layer

`lib/agent/capabilities.ts` names what a run may do — 13 capabilities across
filesystem, process, network, browser, VCS, and MCP — each with a risk class
(read / mutate / external), a tool→capability map, and mode capability sets
that mirror executeTool's existing enforcement. The manifest never widens
what tools.ts locks (contract-tested). This is the vocabulary the future
policy engine, manifest storage, and Policy Simulator consume; drift becomes
a type error instead of a silent divergence.

transports, per-tool grants), Workspace model, durable pause/resume, and

sandbox — stated everywhere it matters.
