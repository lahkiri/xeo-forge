# v1.19.3 — Polish & Pulse

## Summary

Every item in this release came from a user sitting in the product and
listing what felt wrong. That list was the roadmap.

## The picker was invisible

The model popover referenced `rgb(var(--ink-950))` — a token that does
not exist in the design system. Undefined CSS variable → transparent
background → the popover floated as ghost text. All references now use
the defined `--ink-900`.

## Health dots that actually pulse

Dots were static until someone ran the Control Center probe manually.
New heartbeat endpoint sweeps up to 12 enabled models (round-robin,
oldest-checked-first) with cheap basic completions; the picker runs it
on open and every 5 minutes; dots pulse with "checking models…" while
sweeping. Desktop Local: any session. Hosted: admin only.

## Upgrades keep your model

The v1.19.2 `selected` column migration defaulted everything to 0, so
existing installs visually reset their pick to the first enabled row
(the reported "lost my model"). The migration now backfills from the
legacy `model_settings.model_id` row.

## Reasoning effort — the full ladder

New Control Center control next to context settings:

> Default · Off · Minimal · Low · Medium · High · Enhanced High · Max · Ultra

Persisted per model config (`reasoning_effort` column), zod-validated,
and injected into completion requests only when not 'default' — providers
without support ignore it harmlessly.

## Chat swallowing answers — root cause #3

v1.19.1 fixed persistence and the prompt but missed the third layer:
`CHAT_TOOLS` still **offered task_complete** to chat models. The prompt
begged the model not to call it while the tool list invited exactly that.
Removed from the chat surface; chat terminates on natural text stop —
the path that persists the verbatim answer.

## Layout you control

- Workspace sidebar collapses ('‹') and returns ('› Show sidebar').
- Drag its edge to resize between 180–420px.
- Both persist across restarts.
- Work surface received the same double-viewport fix and an explicit
  "← Workspace" exit link.

## Verification

`tsc --noEmit` clean · lint clean · **757/757 tests** · heartbeat and
selection endpoints exercised live against a running dev server with
DB-level confirmation of persisted selections.
