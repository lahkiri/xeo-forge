# Xeo Forge v1.4.1 — OTA Restart Reliability Patch

Xeo Forge v1.4.1 is a focused patch release for the Windows desktop updater. It keeps the v1.4.0 feature set unchanged while tightening the final installation path used by **Restart to update**.

## What changed

- Windows OTA installation now uses one deterministic installer path.
- The downloaded NSIS installer is launched with unattended update arguments and force-run-after-install behavior.
- The implicit install-on-quit hook is disabled for explicit update actions so the application cannot start a second installer invocation during shutdown.
- The existing local update-state file, SQLite database, Local Owner, settings, task history, and selected project path remain outside the installer payload and must survive the upgrade.

## Verification status

This patch is intended to eliminate the interactive NSIS window observed during the v1.4.0 real-device test. Final release acceptance still requires a real Windows upgrade from installed v1.4.0 to v1.4.1, followed by verification that the new version opens directly and that `userData` and SQLite remain intact.

## Upgrade guidance

The minimum recommended installed version for receiving air updates remains **v1.3.1**. Users should always update to the newest published version. Users on v1.3.0 must install an OTA Bootstrap build manually once before receiving later air updates.

## Scope

This is a reliability patch. Browser write permissions, domain allowlists, sensitive browser actions, ClarificationCard expansion, Strict Local, redaction, and code signing remain outside this patch unless separately documented.
