# v1.19.0 — Alive

## Summary

The first-open release — and the first built with an outside contributor.
Everything here serves one goal: a visitor installs Xeo Forge, presses one
button, and watches the governance loop breathe before configuring anything.

## UI rebuild v2 (@malekradwan1300)

A Hermes-inspired unified workspace: Chat / Explore / Work / Execute
surfaces in one shell, a neutral Geist system with dense dark styling,
a multi-provider model catalog (browse models per provider), split
Settings (Providers / Runtime / Memory / Profiles / Skills / MCP), and
**Skill Hub discovery** — search the open skills.sh directory from
inside Xeo. Merged as PR #16.

## Watch a governed run — no setup

The first-open problem: every surface empty, and a real run needs a
provider. Solved with an honest recording: a 24-event golden run
(read-only inspection → plan → approval moment → gated build writes
with live file activity → pytest exit=0 → verification pass → memory
proposal) seeds as a REAL task and paces itself on screen through the
exact components live events use. Labeled `recorded demo` everywhere;
skippable; Desktop Local only; reuses the previous demo instead of
piling duplicates.

## Provider health probe

The live-session finding that motivated this: some providers serve
plain completions fine but reject every streaming request carrying
tools — Chat works while every Planning/Build run fails with an opaque
error. The new probe asks the provider both questions and reports an
honest verdict (`healthy` / `stream_tools_unsupported` / `auth_failed`
/ `provider_down`) with detail text that says what works and what does
not — never accusing your key when the key is fine. One retry absorbs
free-tier flap. Find it in Control Center: **Test governed-run path**.

## decision is a first-class event

The replay's approval moment emitted `type:'decision'`, which the
timeline silently dropped via its default:null fallthrough — the same
stale-registry failure mode v1.10.0 documented for context_layers.
Now registered, labeled ("Operator decision recorded"), and pinned by
tests so it cannot regress.

## Contract tests for everything above

18 replay-contract tests + 9 provider-health tests pin the scripts,
routes, pacing bounds, honesty markers, authz split, and no-key-echo
guarantees — so future redesigns cannot silently break the demo or
leak secrets.
