# Xeo Forge v1.7.0 — Memory Foundation

Xeo Forge v1.7.0 promotes the Memory Foundation from Preview to Stable after successful Windows and Linux packaging, artifact verification, smoke checks, and Preview-channel CI validation.

## Included

- A canonical memory lifecycle for proposals, review, activation, expiration, and audit visibility.
- Active memories are injected into agent context only after approval.
- Expired memories remain available for review but are excluded from active context.
- Local Settings exposes memory controls without exposing SaaS Admin surfaces in Desktop Local.
- Stable and Preview release channels are explicit. Stable users remain on the stable feed by default, while Preview remains opt-in.
- Release artifacts and update feeds are validated for platform, version, path, size, and SHA-512 before publication.

## Compatibility

The release preserves the Local Owner, SQLite/userData, project state, Browser Profiles, governed Browser Safety policy, and unattended OTA restart path established in earlier releases.

## Verification

The release candidate passed typecheck, the complete test suite, production build, Browser smoke, Desktop smoke, Linux artifact verification, Windows artifact verification, and a successful Preview-channel GitHub Actions run.
