# Xeo Forge v1.7.0-beta.1 — Memory Foundation Preview

This preview introduces the first end-to-end Memory Foundation milestone for the Local-First Agent Workbench.

## Included

- Persistent memory proposals are created from completed build runs and remain in `proposed` status until reviewed.
- Reviewed active memories are injected into agent context through the canonical `agent_memories` store.
- Expired memories remain visible for review and audit but are excluded from active agent context.
- Local Settings exposes the memory lifecycle without reopening the SaaS Admin surface.
- Stable/Preview release channels are now explicit: this build uses the Preview `beta` feed and is not the default stable update.

## Preview validation

The preview must pass typecheck, the complete Vitest suite, production build, browser smoke, desktop smoke, and release-artifact verification for both Windows and Linux before promotion to `v1.7.0` Stable.

Preview users should keep a backup of important project data and report regressions before the stable promotion.
