# v1.19.2 — The Listener

## Summary

Every defect reported after the 1.19.1 update, fixed and shipped. This
release exists because a user sat down, listed what actually broke, and
the team treated that list as the roadmap.

## Sessions open correctly again

Opening any chat or work session pushed the entire view below the fold:
`ChatClient` rendered `h-screen` inside the app shell's own `h-screen
overflow-hidden` container — two competing full-viewport heights. The
thread now fills its actual container, and a visible "← Workspace" link
returns to `/chat` from anywhere.

## Model selection persists ("I lost my model")

Nothing was actually deleted — but the picker's choice was never stored,
so every reload recomputed the active model as *first enabled row*, which
reads exactly like data loss. Now: a `selected` marker (one per user) on
`provider_models`, `POST /api/providers/select` with owner-or-admin
authz, and the catalog's active pair honors the persisted pick. Your
choice survives restarts.

## Model picker, rebuilt

- **Search**: type to filter by name or model id instead of scrolling.
- **Health dots** per model — green = probe verified it works, amber =
  unverified, red = known-incompatible with governed runs (stream+tools
  rejected). Fed by the Control Center "Test governed-run path" probe.
- The health route echoes which provider/model pair it probed so the
  cache is accurate.

## Terminal unbroken

The terminal rendered as overlapping unstyled text because the xterm base
stylesheet was never imported. It is now (in `globals.css`, so test
environments loading the component without CSS handling keep passing).

## Provider quick-start presets

One-click prefill for **OpenAI, Anthropic, Google Gemini, DeepSeek,
OpenRouter, z.ai (GLM), Groq, Mistral, and Ollama (local)**. Custom base
URL + key remains fully supported; after connecting, import all models
via the provider's `/v1/models` discovery or add exactly one model by id.
Both paths were already live; presets just remove the cold start.

## Also

- The thinking block renders **above** the answer it describes.
- Settings dropdowns: real height, readable text, custom chevron.
- The Watch-demo card is visible on both Chat and Work tabs in Desktop
  Local mode.

## Verification

`tsc --noEmit` clean · **757 tests passing across 40 files** · selection
persistence verified end-to-end against a live dev server (seed → select
→ persisted row confirmed).
