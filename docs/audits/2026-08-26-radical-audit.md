## المحور الأول: الأعطال المرصودة سابقاً

### عيب A1 — تحية "مرحبا" في Chat تنتهي FAILED بلا رد يُذكر [مُختبَر] — الشدة: حرج
**خطوات الإعادة:** إنشاء مهمة chat بهدف `"مرحبا"` عبر `POST /api/tasks` → مراقبة task_events.
**الدليل الخام (3 جلسات منفصلة):**
- `fbd22863`: استدعاءات أدوات = `[file_list, git_op, todo_update ×6]` → **failed**: "No measurable progress for 6 consecutive iterations" — 5,815 حدثاً قبل الموت
- `55a92db2`: `[file_list, todo_update]` → ظلت running >4 دقائق لتحية
- `6cdeeeef`: `[file_list, todo_update ×4, file_list]` → failed بنفس رسالة الركود
**الجذر [استنتاج من الكود]:** `CHAT_TOOLS` (tools.ts L60) يتضمن `todo_update` و`git_op` و`http_request`؛ البرومبت البنائي يدفع النموذج لـ"العمل" ف يستدعيها في تحية، ثم progress model (الفعّال في chat أيضاً — loop.ts L1116/L1137/L1271 بلا بوابة mode) يقتل المهمة. **الحارس يعمل — لكن النتيجة النهائية للمستخدم: خطأ بدل ترحيب.**
**المعيار (الثبات والوضوح): مكسور بأقسى شكل ممكن.**

### عيب A2 — الرد المتدفق لا يُحفظ عند الفشل/الإلغاء [مُختبَر] — الشدة: حرج
**الدليل الخام:** جدول `messages` في DB الحية: `{'user': 7}` — **صفر رسائل assistant عبر 8 مهام**، بينما `task_events` يحتوي 13,671 حدث text.
**الجذر [مُختبَر بالقراءة + مطابقة السلوك]:** `failRun()` (loop.ts ~L1375) يكتب status+error+done فقط — لا يمرر `chatTextBuffer`. نفس الشيء لمسار الإلغاء (L947-951). إصلاح v1.19.1 حفظ الرد في مسار النجاح فقط.
**المعيار: مكسور** — المستخدم رأى الرد يُكتب ثم يختفي للأبد بعد أي فشل.

### عيب A3 — الإلغاء في نافذة cold-start يفشل بصمت مع استمرار الاستهلاك [مُختبَر مرة واحدة] — الشدة: متوسط-حرج
**الدليل الخام:** مهمة `249e8fcf`: cancel عند t≈+8s رجعت `{ok:true, signalled:false, "no live loop was found"}` — لكن events استمرت تتدفق **97 ثانية بعدها** (آخر حدث 07:58:28 مقابل الإنشاء 07:56:29).
**الجذر [استنتاج]:** سجل `controllers` هو Map على مستوى module (cancellation.ts L23) — عرضة لانفصال نسخ الـbundle بين مسار اللوب ومسار cancel في dev/edge حالات. إعادة الاختبار على server دافئ نجحت (`signalled:true` وتوقف خلال ≤5s، latency 1.83s).
**المعيار: يكسر الثقة** — زر الإيقاف كذب مرة واحدة تكفي.

### عيب A5 — 503 auth_unavailable يقتل مهام mid-stream بلا تصنيف قابل للفهم [مُختبَر] — الشدة: متوسط
